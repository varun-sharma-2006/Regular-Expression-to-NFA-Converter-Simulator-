        Part B · AI Features

        10. Natural language → Regex

        Describe a language in English. The AI writes a regex, our parser validates it, and the automata pipeline above draws it.

        11. AI Regex Verifier

        Checks a regex with examples (DFA simulation) and, optionally, proves it equal to an expected regex (product automaton). Works without an API key. Separate examples with commas or new lines; write ε for the empty string.

        12. Language operations (closure properties)

        Combine two regular languages with the product automaton, or complement one. The result is again a DFA, which proves regular languages are closed under these operations.
